# Security Policy

## Responsible Disclosure

We take security seriously. If you discover a vulnerability, please report it responsibly so we can address it before it becomes public.

## Security Contact

For security inquiries, please contact the maintainers via the project's issue tracker under the `security` label, or email the project maintainers directly.

## Supported Versions

We actively support the latest version of smart-pill. Older versions may not receive security patches.

| Version | Supported |
|---------|-----------|
| 0.5.x   | ✅         |
| < 0.5.x | ❌         |

## Reporting Guidelines

1. **Do not** disclose the vulnerability publicly before a fix is available.
2. Provide a clear description of the issue and steps to reproduce it.
3. Include any relevant logs, configurations, or environment details.
4. We will acknowledge receipt and provide updates on our progress.
5. A patch will be developed and released, and credit will be given to the reporter.
